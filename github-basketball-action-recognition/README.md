# Basketball Action Recognition

篮球视频动作识别与人球交互研究项目。

本仓库保存可复现的研究代码、评测脚本和项目文档，当前对应 2.0 人球识别基础实验。项目研究内容包括：

- 球员与篮球检测、跟踪和球员图块提取；
- R(2+1)D-18、MViT v2 S 和 BallFused 动作识别基线；
- 人球相对位置特征与辅助球流融合；
- 帧级分类、事件级定位、mTAP 和解码器评测；
- 检测球输入与 GT 球输入之间的鲁棒性分析。

## 仓库结构

```text
scripts/   训练、推理、解码和评测脚本
docs/      阶段总结、训练机任务单和回传评审
```

原始视频、数据集、模型权重、训练日志和实验输出不上传到公开仓库。它们通过本地路径或独立存储管理。

## 当前状态

2.0 已完成基线、评测重装、解码网格、分类器赛马、语义门控和 BallFused 初步验证。当前重点是补齐检测球轨迹、完成真实输入事件级评测，并在独立 hold-out 数据上验证泛化能力。

当前结果和限制见 [`docs/2.0人球识别_训练机回传评审_20261030.md`](docs/2.0人球识别_训练机回传评审_20261030.md)。

## 研究纪律

- GT 输入与部署输入分开报告；
- 不把验证集结果写成独立测试结果；
- 关键实验保留多随机种子和完整配置；
- 小于 5 个百分点的差异先按噪声处理；
- 失败实验和负结果与正结果一起保留。

## 环境

训练环境依赖项目实际使用的 PyTorch、CUDA 和 Ultralytics 版本。正式安装清单将在环境复核后补充，避免把训练机私有路径写进仓库。
