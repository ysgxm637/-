## 二、可信发现

### 1. 评测链可复现

`evaluate_v2` 对 `probs0` 和 `r21d_gnd` 的复跑结果与历史日志逐位一致；60fps 和 72 个验证集 GT 事件对账一致；视频级训练/验证划分通过泄漏检查。

评测审计发现一个需要论文记录的口径问题：帧级多对一轨迹映射可能重复计数，但事件级已经去重。该问题不会推翻现有配置排序，后续论文需明确选择口径并说明。

### 2. BallFused 的真实输入结论只能写到“部分成立”

| 球输入 | 球单流 Macro-F1 | 两流融合 Macro-F1 |
|---|---:|---:|
| GT 球 | 0.678 | 0.817 |
| 检测球 + 插值 | 0.389 | 0.805 |
| 检测球，无插值 | 0.381 | 0.802 |

可以确认：

- 球单流对球输入质量高度敏感，GT 到检测球下降 28.9pt；
- 两流融合由外观流兜底，GT 到检测球只下降 1.2pt；
- 检测球融合相对无球外观集成 0.781 仍有 +2.4pt，但低于 5pt 铁律，不能宣布显著；
- 外观较弱的 1000–1235 帧段出现 +7.7pt，说明球信息可能主要用于纠偏。

必须保留的限制：检测球轨迹只覆盖视频 3，视频 5 缺位；当前结果是 clip 级，不是完整部署事件级；融合结构是辅助球流，不等同于 R(2+1)D/MViT 的早期 BallFused 分支。因此不能写成“BallFused 已在真实部署输入上验证成立”。

### 3. 当前不应继续训练

训练机没有发现足以触发重训的明确失效：融合在已有检测球口径仍有正向信号，跟踪/图块阶段尚未分析，模拟漏检和抖动也未完成。

当前唯一有明确假设的训练方向是：用检测球轨迹、插值和模拟漏检构造训练输入，减少 GT 与部署输入的域差。该方向必须等完整 v3/v5 球轨迹和条件 4/5/6 对照完成后再决定。

## 三、下一轮训练机任务

### P0：补齐球轨迹落盘

在部署脚本中增加逐帧球中心、可见性、插值状态和 track/video/frame 元数据落盘，同时把完整命令行参数写入日志。不得改动旧输出目录。

### P1：补齐 BallFused 输入条件

对 v3 和 v5 生成完整检测球轨迹，完成：

- 检测球；
- 检测球 + 插值；
- 模拟漏检；
- 轨迹抖动；
- 可见率/连续性质量分档。

在 GT、检测和模拟输入下分别报告 clip 级与事件级指标，不能混合口径。

### P2：完成跟踪与图块质量定位

输出球员轨迹连续率、ID Switch、HOTA/IDF1（可计算时）、图块有效率和代表性失败可视化，回答跟踪是否是动作识别瓶颈。

### P3：完成一次 BallFused 事件级复评

只有在 P1 完成后，才把 BallFused 概率接入事件级评测，比较 `mF1@0/10`、`mTAP@0/10`、逐类召回、过报和漏检。

### P4：根据判据决定是否训练

只有检测球口径下融合相对 0.805 的提升预期超过 5pt，且存在可自动生成的训练输入时，才启动检测球/混合质量训练；训练至少 3 个 seed。
